# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

`AGENTS.md` is the authoritative, mandatory rulebook (locked stack, design-token rules, money/privacy/offline rules, Definition of Done, reporting format). Read it before changing code; this file only adds what is needed to get oriented. Product spec is `docs/PRD.md`; screen designs are in `docs/design/screens/<NN-name>/` (see AGENTS.md §16 for the source-of-truth order).

## Commands

```sh
npm start                 # expo start (dev client)
npm run android | ios | web
npm run lint              # eslint + prettier -c
npm run format            # eslint --fix + prettier --write
npx tsc --noEmit          # typecheck
```

- AGENTS.md requires `npm run check` (typecheck + lint + tests) to pass, but **that script and a test runner (`jest-expo`, `@testing-library/react-native`) are not set up yet**. Don't claim "check passes" until they exist; adding them means new dependencies/scripts, so ask first.
- `android/` is generated by `expo run:android` (prebuild). The first build downloads Gradle from `services.gradle.org`; network timeouts there are environmental, not code bugs.

## Architecture

Early-stage Expo SDK 56 / React Native 0.85 / React 19 app (Expo Router, NativeWind v4 on Tailwind 3, TypeScript 6 strict, `@/` alias = repo root). Currently only `app/` (index, modal, +not-found, +html, `_layout`), `components/ui/Text.tsx`, `components/nativewindui/*`, `lib/`, and `theme/` exist. `engine/`, `features/`, `supabase/`, `types/` are planned layers (empty) described in AGENTS.md §3 and PRD.

Layering (enforced by convention): `app → features → components/finance → components/ui|nativewindui → theme`; `engine/` (pure TS, no React/Supabase) and `lib/` are importable from anywhere. Only `features/*/api/` may call Supabase; screens use `features/*/hooks` (React Query).

### Design tokens live in three places that must stay in sync
`global.css` (CSS variables), `tailwind.config.js` (maps classes to the variables), and `theme/tokens.ts` (hex values for code that can't use `className`: charts, navigation theme, status bar). `theme/colors.ts` / `theme/index.ts` are the NativeWindUI-style theme exports. Components and screens must use token classes only (no hex, no raw colours); the tokens file is the one place hex values are allowed. Never change token values unless the task says so.

### Components
- `components/nativewindui/` holds free NativeWindUI primitives (Button, Text, Icon, ThemeToggle) — don't edit except to fix bugs, and never add Pro code.
- `components/ui/` is for in-house primitives; the design-system `Text` (variants `display|title|heading|body|label|caption`) must be used in screens instead of `react-native`'s `Text`.
- Every new/changed component must also be added to `app/dev/gallery.tsx` (not created yet).

## Gotchas
- Git branch is currently `master` while the main branch is `main`; workflow uses `feat/…`, `fix/…` branches and Conventional Commits.
- Don't install packages, edit `app.json`/`eas.json`, or hand-edit `types/database.ts` without being asked (AGENTS.md §13). Note `app.json`, `package.json` etc. have uncommitted scaffold changes in the working tree.
- Phase 4 (SMS/email reconciliation) must not be built, including its tables, unless a task says so.
